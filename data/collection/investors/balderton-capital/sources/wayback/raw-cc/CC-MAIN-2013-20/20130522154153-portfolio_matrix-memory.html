Matrix Memory

Matrix Semiconductor, Inc. created and developed the world’s first three-dimensional integrated circuits. Matrix’s first product, Matrix® 3-D Memory (3DM), was a low cost, high density line of permanent, one-time programmable, non-volatile memory, compatible with existing standards. Sandisk acquired Matrix for $260 million in 2006
