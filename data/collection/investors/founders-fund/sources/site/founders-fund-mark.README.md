# founders-fund-mark.svg

The firm's square mark, redrawn as a vector on 2026-10-06 from the site's own 152 px icon (https://foundersfund.com/apple-touch-icon-152x152.png, saved beside this file): four full-width colour bands, boundaries at the rows where the mean row colour jumps, each band filled with its modal colour. The site declares no vector of the mark (its only SVG is the 'FOUNDERS FUND' wordmark, logo-ff-2015.svg) and every raster it declares is smaller than the 256 px master, so a raster source would be upscaled.
